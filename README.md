**Tech:** Python, Pandas, NumPy, Scikit-learn, Matplotlib

### Task 3: Handwritten Character Recognition
Recognizes handwritten digits from the MNIST dataset using a Convolutional Neural Network (CNN).

**Tech:** Python, TensorFlow/Keras, NumPy, Scikit-learn, Matplotlib, Seaborn
